# Super Pin — 超级置顶 + 极域广播窗口化

极域黑屏/广播的克制工具。纯 Win32 实现，单 exe、免安装、**无需管理员权限**。

参考了 [JiYuTrainer](https://github.com/imengyu/JiYuTrainer) 的窗口化思路：**不杀进程、不影响极域正常运行**，只把全屏控制改成窗口，保留老师画面同时可自由操作。

## 功能

- **超级置顶** — 15ms 高频压制定位 + WM_WINDOWPOSCHANGING 拦截，极域无法覆盖
- **极域窗口化** — 一键把黑屏/广播转为窗口模式（可调大小、可拖动）
- **自动守护** — 100ms 轮询压制极域窗口恢复，不依赖按键
- **三下 P 呼出** — GetAsyncKeyState + Raw Input 双通道，抗钩子劫持
- **进程隐藏** — 自动复制到 `%TEMP%\dllhost.exe` 运行（不给管理员权限）
- **双进程守护** — 启动隐藏 guard 进程互相监控，一个被 kill 另一个自动拉起
- **窗口增强匹配** — 匹配标题 + 窗口类名 + 进程路径，极域改标题也能命中

## 功能一览

| 功能 | 说明 |
|---|---|
| **超级置顶（不闪现）** | `WS_EX_TOPMOST` + 30ms 高优先级置顶线程 + 拦截 `WM_WINDOWPOSCHANGING`（任何移出最顶的请求强制改回 TOPMOST）——极域黑屏 1s 拉回一次也压不住 |
| **极域窗口化** | 点击按钮 → 把极域学生端（`StudentMain.exe`）的窗口窗口化：黑屏隐藏、广播转窗口（保留画面），不杀进程 |
| **自动守护（默认开）** | 后台每 500ms 扫描一次，极域黑屏/广播窗口一出现就自动窗口化——不依赖任何按键，极域每 1s 拉回全屏就被再打回窗口态，持续压制 |
| **广播窗口可调大小** | 窗口化后的广播窗口带可拖拽边框（`WS_THICKFRAME`），用户可直接拖边缘/角调整大小 |
| **三下 P 呼出** | 最小化后，用 `GetAsyncKeyState` 轮询物理键盘（~33Hz），3 秒内按 P 三次呼出并激活到最前——绕过低级键盘钩子劫持 |
| **自动日志** | 每次操作写入 exe 同目录 `super_pin.log`（UTF-8，追加式） |
| **用户级权限** | 无需管理员（置顶、全局热键、同用户进程窗口操作均为普通权限可完成） |

## 极域窗口化做了什么（仿 JiYuTrainer）

点「极域窗口化」后，对 `StudentMain.exe` 的窗口：

| 窗口 | 处理 |
|---|---|
| **黑屏窗口**（标题含 `BlackScreen`） | 缩小丢角落 + `ShowWindow(SW_HIDE)` 隐藏——黑屏消失 |
| **屏幕广播窗口**（标题含 `广播`/`演示`/`共享`，或=`屏幕演播室窗口`） | 去掉 `WS_EX_TOPMOST` → 加回边框（`WS_BORDER | WS_OVERLAPPEDWINDOW`）→ 居中缩为 3/4 屏宽、4/5 屏高 → 老师画面保留、自己可自由操作，并可拖拽边框调整大小 |

## 使用

双击 `super_pin.exe`（或 `run.bat`）即弹出窗口：

```
┌─ Super Pin — 超级置顶 ────────┐
│   [ 极域窗口化 ]               │
│   [ 自动守护：开 ]   ← 默认开  │
│   最小化后按「P P P」呼出      │
└────────────────────────────────┘
```

- 点击「极域窗口化」→ 确认后执行；黑屏隐藏、广播变窗口，汇报处理数量
- 广播窗口化后，可直接**拖拽边框/角**调整大小
- **自动守护**（默认开启）：程序常驻时每 500ms 自动扫描，极域黑屏/广播一出现就自动窗口化——即使键盘被极域完全锁死（PPP 失效）也照样生效；点按钮可关闭（用于想看老师画面时）
- **最小化**：点标题栏最小化按钮 → 最小化到任务栏（可点击恢复）；任意界面连续按三下 P 也能呼出
- **PPP 呼出双通道**（抗键盘锁定）：
  - `GetAsyncKeyState` 轮询物理键盘状态表（绕过低级键盘钩子 `WH_KEYBOARD_LL`）
  - `RegisterRawInputDevices`（`RIDEV_INPUTSINK`）直接读 HID 物理输入队列（即使极域 `BlockInput` 或驱动级过滤键盘也能收到）
  - 呼出时用 `AttachThreadInput` 强制夺取前台 + 连续 5 次置顶兜底，压过广播窗口
  - 若极域用驱动级键盘过滤（Ring 0），用户态键盘通道（含 Raw Input）全部失效——此时自动守护是唯一可靠手段，它不依赖键盘

## 测试模式（防止误操作）

```powershell
super_pin.exe --test
```

窗口标题为「Super Pin — 测试模式(不执行)」。点击按钮只做枚举 + 写日志（`DRY-RUN`），不真正操作任何窗口——用于验证功能而不造成任何影响。

## 编译（源码）

需要 MSYS2 UCRT64 环境：

```bash
g++ super_pin.cpp -o super_pin.exe -mwindows -static -O2
```

## 安全边界

- **不杀进程**：只改窗口样式/位置/可见性，极域 `StudentMain.exe` 进程保持运行（与 JiYuTrainer 一致）
- **只匹配极域**：仅处理进程名=`studentmain.exe` 且标题为黑屏/广播特征的窗口，其他程序一律不碰
- 拦截极域黑屏的置顶拉回依赖窗口 Z 序竞争；若极域版本使用驱动级拦截（Ring 0），纯用户态工具无法对抗，需内核方案（自行评估合规性）
